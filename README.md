# 🤖 Automação de Tickets Zendesk

Projeto desenvolvido para varredura automatizada de palavras-chave em comentários de tickets do Zendesk, utilizando **Python**, **Playwright** (com conexão CDP) e interface gráfica responsiva em **Flask**, **TailwindCSS** e **JavaScript**.

## 🚀 Tecnologias e Frameworks utilizados:
- Python 3.12
- Playwright (Automação Web de performance)
- Flask (Criação de APIs locais)
- TailwindCSS (Interface Web com suporte a Modo Escuro)
- html2pdf.js (Módulo de relatórios nativos em PDF)
